The target `frDesign` is owned by `TritonRoute::design_` and its public getters return the same global in-memory model used by native worker initialization. The native Logger error template logs synchronously and only then throws `runtime_error("DRT-1231")`. Therefore the sink executes before stack unwinding or router teardown. The observer owns no router data and retains no raw AP or terminal pointers after the callback.

At the failure site, `FlexDRWorker::init` calls `initNets` before `initGridGraph`. Native `initNet_term_helper` reads `inst->getPinAccessIdx()`, the terminal's preferred AP vector, the master pin's selected access pattern and `getNoRotationTransform()` on copies of AP points. The observer repeats those reads only. `frAccessPoint` getters directly read stored members; `frInst.cpp` 29–33 constructs a transform copy and changes its copied orientation to R0, without Logger calls or state writes. Terminal pin shapes are copied and transformed with the instance's full DB transform.

PA generation finishes before detailed routing starts. In `FlexDR.cpp` 705–726 each worker's main executes inside an OpenMP parallel loop; exception capture/rethrow occurs after the loop joins. Global worker commits are in `endWorkersBatch` 793–808, explicitly single threaded, after `processWorkersBatch` returns. Thus a sink invoked from a worker's original error emission cannot overlap those global commit calls. The retained init/maze/end/query sources have no setters for master AP vectors, preferred AP vectors or instance PinAccessIdx. Dirty PA regeneration in `fixMaxSpacing` is a main-thread operation after a completed search/repair iteration, not concurrent with a worker batch. The proposal is restricted to normal, non-distributed routing with the same qualified adapter and four-thread scheduler; it is not a general proof about arbitrary concurrent API calls.

The sink uses `base_sink<std::mutex>` for its own event ordering and raw `write()` to its new owned file. Its callback never invokes Logger, formatter reconfiguration, Writer, PA, routing, shared geometry setters, or the installation/removal methods. Consequently it does not recursively enter the native Logger. Installation uses public `addSink` before routing; removal uses public `removeSink` after the native command and joined workers return. Existing sinks are retained, with the stock native `%v` formatter. Output or collection errors remain incomplete observations; they never suppress or replace the native exception.

These are source-backed admission arguments, not measured native qualification. The separate four-thread fixture must prove message thread IDs are populated and distinct in this actual binary. The saved-C14 end0 control must prove geometry/rule/count/scope parity with the original adapter, and the error probe must reproduce its prior completed tables and original fatal error. Observer overhead can affect execution timing; the same-source parity gates cannot be waived on that basis. Worker-private endpoint selection, ext/DRC boxes and maze costs remain outside this observer's claim.
