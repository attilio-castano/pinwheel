# Path-specific fanout914/913 hold-loss assessment

The assessment is **inconclusive**. It does not establish that virtual buf_4 sizing can retain 50 ps, and it does not establish that sizing would fail. The fixed-RC counterfactual stopped at its mandatory unchanged-control gate. No virtual timing run, physical resize, placement change or routing change occurred. Both physical buffers remain buf_1.

The intended method used a standalone OpenSTA ConcreteNetwork, the three pinned Liberty sets, exact SDC and unchanged saved wire SPEF. Only the two instance master tokens were changed in a derived virtual netlist; every port and connection remained identical. Liberty input-capacitance ranges, parent loading, downstream slew and endpoint constraints would be propagated by STA. Actual path reselection across both data transitions, setup and hold was required for all 257 endpoints per driver. The 50 ps acceptance floor reserved an additional 1 ps for serialized-model metrology. The earlier blanket 1 ns admission guard was preserved as historical evidence, not silently replaced by a successful tighter bound.

All three unchanged standalone controls completed. Original native estimate_parasitics STA remains the authoritative retained baseline: it evaluated the native RC network before export, including the pin-node wire capacitances. This finding concerns the later lossy SPEF export/re-import path and does not replace or invalidate those retained native results.

The pinned exporter writes ground CAP entries only for nodes with no real pin attached. The native estimator places half of each pin-to-grid wire-stub capacitance on the real pin node and the other half on the grid node. D_NET totals include that capacitance, while the serialized CAP body omits the pin-node half. The resulting standalone network loses 15.525078891 pF across all 28,948 annotated nets: declared totals sum to 200.230083773 pF but serialized ground CAP entries sum to 184.705004882 pF. Both data and clock networks are affected. This mechanism is bound to exact pinned source hashes in the export diagnosis; no capacitances were adjusted to fit timing.

For _11039_, the declared wire capacitance is 0.00392221 pF while the serialized ground CAP sum is 0.003617105 pF. Missing wire capacitance is 0.305105 fF. The missing amounts are 0.871571 fF on net914 and 1.565775 fF on net913. Typical native _17772_/Y early/falling load is 5.964 fF versus 5.658 fF after the standalone import, directly exposing this loss. Redistributing each net's aggregate deficit would lose attachment locations and is not an acceptable repair.

The independent analytical work corrected SRAM bus-pin lookup and handled actual constraint-table axis order in a new helper, preserving prior helpers. Twenty parser controls passed. The limiting fast FF hold constraint reproduced within 0.001 ps; its maximum change within the characterized data-slew domain is only about 1.625 ps for current_control[5] and 0.419 ps for current_control[21]. That is useful local evidence, not an all-endpoint sizing bound: candidate slew domain and downstream delay changes remain unqualified.

A zero-tail screen removed every delay after fanout914/A on retained early paths. The particular cached_branch[19] to current_control[5] path has a conditional 87.233 ps reserve after its in-domain endpoint hold drift. This assumes upstream loading cannot accelerate arrival and the removed tail cannot have negative delay. It does not clear the whole affected cone: even using current endpoint requirements, 14 typical, 7 slow and 31 fast retained samples are below 50 ps. The worst fast screening margin is minus25.515 ps at SRAMstorage0/A_ADDR[2]. These are insufficient lower bounds, not predictions that the actual sized design fails. A complete bound would also need all launch-path reselection, nonnegative tail justification and endpoint constraints over possible candidate slew.

The existing fast native reports contain 99 sampled cell arcs below a library slew-table minimum and 274 of 1,028 hold endpoint samples below the STD data-slew minimum, spanning 74 FF endpoints. The analytical helper neither extrapolated nor silently clamped these samples. Native STA may model them through extrapolation, which must remain distinct from a characterized-domain or silicon guarantee. Fast logic/IO is minus40 C while SRAM is minus55 C, and the 167 unannotated drivers per corner remain disclosed.
