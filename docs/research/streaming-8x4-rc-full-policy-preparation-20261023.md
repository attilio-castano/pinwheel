# Fresh complete-universe d.25 policies

These are new, HOST-prepared native policies. They preserve the original failed
native policies, geometry, references, sources and receipts. No Native solver
was run by preparation or the tests. Root must review and admit each exact command
through the shared resource guard.

The preceding conditioning packets were independently reopened from raw logs and
exact resource receipts. Layered M1 d1 retains its warning failure; Jacobi d.25
passes the coarse numerical gates with the same 9,635 panels and 5,171,923 links
instead of 231,497. The uniform development case's fixed two-level128/d.25 ladder
passes all five numerical leaves and final matrix changes 0.468927% / 0.146389%.
Those are development measurements; they do not qualify either full universe.

The uniform profile preserves the historical U's original 2^-20 m coordinate
unit and the ten finite wires' original 1e-6 m unit. It does not rescale U to match
the finite wires. Every case's exact original files and per-case conversion are
bound separately. All meshes remain 0.000383703, 0.000248446, 0.000172698,
0.000086349 and 0.0000431745.

Both profiles retain fatal warnings/nonconvergence, complete matrix names and
dimensions, Maxwell signs and row sums, 1% native matrix reciprocity, positive
symmetric energy, exact preconditioner and complete terminal-footer gates.
Acceptance still requires the final two complete matrix changes at most 2%,
length slopes within 5%, finite-ground-extension changes at most 2%, and every
declared independent reference comparison within 10%. Layered comparisons retain
complete wire self, coupling and ground-sum comparisons. Held-out cases, all
MIN/TYP/MAX cases and all expected length/extension combinations are mandatory.
No subset, adaptive mesh, automatic retry or tolerance override is supported.
The uniform 0.32 µm width was originally held out, but its failed coarse case
informed the d.25 diagnostic. This complete 55-call rerun is development and
confirmation data, not new blind holdout evidence; the original roles remain
byte-for-byte historical authority and no independent holdout status is restored.

Original FVM authorities remain under their own identities. The M1 packet copies
all 25 original raw reference outputs/logs, plan04, proposal and resource receipt;
the uniform packet copies its eight-case FVM report, original plan04, proposal and
resource receipt. Verification rederives those exact original numerical results
and joins their original source/command/input/cleanup/shared-lock authority.
The old HOST-only uniform receipt's missing container field is accepted only for
its exact pinned HOST command and historical process cleanup scope. The original
reference results are never relabelled with a new native plan hash.

Each Native call has a 120-second limit, one CPU, 6 GiB without extra swap,
512 MiB scratch and 128 PIDs. No next call starts without its 120 seconds plus
cleanup reserve remaining. A numerical failure stops that candidate and retains
its prefix. Measurement completion, all-leaf numerical acceptance and limited
pilot acceptance are separate: even a complete numeric packet needs independent
mesh/length/domain/reference readback. A failed final leaf may close measurement
membership while keeping numerical acceptance false. Failed reaping never closes
measurement custody.

New `streaming_8x4_rc_full_{policy,execute,readback}.py` sources use an explicit
23-file local source closure. The reopener checks every fresh leaf and exact
resource policy before running unchanged numerical comparison helpers. It does
not dispatch new receipts through an old schema or substitute a new plan into an
old execution authority. A downstream consumer must call `closed_authority` on
the new typed receipt; a prefix, old receipt or failed readback cannot qualify.
All full-process-model and qualified-timing fields remain false after any pass.
