# Initialized UART package sessions

Implemented 2026-09-30, following the
[approved proof plan](../research/uart-session-proof-plan.md) and the delivered
[UART supervisor candidate](uart-supervisor.md). The initialized relation,
lifecycle prefixes and continuous wire endpoint are kernel checked. Fresh integrated validation passed on 2026-10-05. The additive
[manifest](../../physical/experiments/uart-session-results.json) binds the
successful receipts, source/tool/generated bytes and preserved attempts.

The result connects the emitted package to an independent UART receiver through
actual reset, certified serial upload, delivered ARM, repeated reception and the
declared reset/reload lifecycle. Memory is a lawful single-port contract; initial
memory contents, Q and represented register state are arbitrary. The package
relation derives resident-image ownership, requested SRAM words, execution,
supervisor controls and mailbox correspondence after the initialized boundary.

## Declared lifecycle

An initialization episode uses three asserted-reset edges and two released idle
edges, followed by an actual serial upload of a certified canonical UART image
and two sampler drains. It accepts COMMIT and establishes disabled mode 0, no
staged upload, a reset receiver and an empty mailbox. No initial SRAM contents,
registered Q or represented controller/observer state is prescribed.

Resident segments allow arbitrary receive samples, host page selection,
consumption and overrun clearing. Their input domain excludes a new external
initialization and accepted replacement COMMIT; those operations have separate
boundary constructors. Enabled loader commands are rejected by the supervisor,
and command 7, STOP and nonquiet rearm delays follow the independent reference.
The certified image and memory law establish each execution step internally.

A replacement starts at a decoded STOP command and a declared settled serial
boundary, then delivers a qualified upload. A completion coinciding with STOP receives its ordinary
pre-edge mailbox transition. Old pending packets retain their original epoch
and configuration through the upload and subsequent ARM. External reset flushes
the old pending packet once; the remaining reset/release and upload edges have
empty receipts before a newly established epoch. Lifecycle replacement and
restart labels strictly increase, distinguishing epochs with identical bytes
and configurations.

Receipt histories track accepted, delivered, dropped and flushed occurrences.
Equal consecutive bytes remain separate occurrences. Consume plus arrival,
clear plus drop, repeated stalls and repeated epochs use the same retained
buffer rules. Arbitrary power-up packets carry an unknown origin. The proof
uses ghost ownership only and adds no hardware tags or counters.

The transport layer gives meaning to every represented package state. UART
interpretation begins only at an established certified-image boundary. A
retained packet keeps its origin when execution resets or the image changes;
generic fault packets require their own interpretation.

Safety permits arbitrary receive values and host stalls. Reception progress
requires the existing strong stream bound, sampler-age conditions, matching
external waveform and quiet consumed commands during uninterrupted rearm
windows. These digital premises do not qualify analog sampling or a board
frequency.

The sampler consumes physical input edge `n + 1` at package edge `n + 3`.
The first two consumed edges use the existing sampler stages. The timing bridge
keeps those prefix values explicit, proves their connection to the external
waveform and derives activation from the admitted ARM edge. Its phase bridge
aligns the actual pre-edge completion observer with the existing post-step stream
while retaining the first consumer/clear receipt.

`PairedStreamProgram.retained_initialized_lifecycle` is the all-prefix emitted
package endpoint. The reference uses the independent UART receiver during
resident segments and STOP, and the generic package during reset/upload edges.
Its domain is a finite path of admitted resident controls, certified UART
replacements and external reset/restart episodes. The path supplies no new
execution relation: each relation follows from the preceding proved boundary.

`PairedStreamUART.initialized_continuous_uart` starts from the same arbitrary
power-up domain and actual reset/upload, locates the qualified serial ARM edge,
and continues through its original trailing samples into future physical pins.
The timing premises apply to that full continued history. Receive progress is
measured from the admitted edge, so the sampler drains are not silently skipped.

Accepted replacement with a non-UART image ends the UART interpretation domain.
The universal generic package transport still describes its physical outputs;
it does not assign UART meaning to the new execution. Packet origin tags are
immutable ghost metadata, rather than a runtime protocol inference feature.

No new hardware registers, FIFO, flow control or physical campaign is part of
this proof work. The historical supervisor and physical receipts remain
preserved. SRAM internal qualification, fast-corner characterization and package
power remain separate gates.

## Reproduce locally

Install the pinned Lean/hardware tools and behavioral SRAM models described in
[development](../development.md). From the repository root, use fresh tags:

```sh
lake build
python3 scripts/check-foundation.py --tag uart-session-foundation-fresh
python3 scripts/check-uart-stream.py --tag uart-session-wire-fresh
python3 scripts/check-stream-readback.py --tag uart-session-readback-fresh
python3 -B -m unittest discover -s test -p 'test_*.py'
python3 -O -B -m unittest discover -s test -p test_uart_stream.py
python3 -O -B -m unittest discover -s test -p test_pinwheel_host.py
python3 -O -B -m unittest discover -s test -p test_stream_readback.py
python3 -O -B -m unittest discover -s test -p test_host_receipts.py
python3 -O -B -m unittest discover -s test -p test_resolved_pads.py
```

The foundation runner checks the default library import closure, audits theorem
axioms, rejects an injected untrusted axiom and runs the focused phase/lifecycle
suites. The wire runner regenerates actual images and timing certificates. The
readback runner independently regenerates and kernel checks the exact core and
package RTL, including unchanged and corrupted controls. Existing run directories
are preserved; a timeout leaves an incomplete receipt and retained diagnostics.

Generated receipts and logs remain ignored local dependencies. Tracked manifest
hashes bind the evidence but do not provide a remote artifact backup.
